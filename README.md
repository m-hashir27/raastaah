# Raasta 2.0 — Karachi Transit Concept

React + Vite prototype with route search, service filters, saved routes, transfer suggestions, animations, bus photography and naturally integrated Pakistan/Palestine flags.

## Run
1. Install Node.js 20.19+ or 22.12+.
2. Extract the ZIP and open the folder in VS Code.
3. Run `npm install`, then `npm run dev`.
4. Open the localhost URL shown by Vite (usually http://localhost:5173).

Build with `npm run build`.

## Important
Independent prototype, not official SMTA navigation. Route labels are manually compiled from public listings and may be incomplete/out of date. Matching stop names do not guarantee the same physical boarding platform. No live tracking, official timetables, fares or verified ETAs. Images are illustrative remote Unsplash photography, not guaranteed to show Karachi's exact fleet; internet is required for photos/fonts. Verify data at https://smta.gos.pk/route-map before presenting publicly.
