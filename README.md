# Raasta 2.0 — Karachi Public Transport Planner

**Making Karachi's public transport easier to navigate.**

Raasta is an independent React + Vite prototype exploring how route planning could improve the public transport information experience in Karachi.

## Features

- **Route planning:** Explore possible journeys between stops.
- **Journey recommendations:** Highlights a suggested option from the available route data.
- **Transfer suggestions:** Shows possible journeys involving a change of service.
- **Estimated travel times:** Approximate stop-to-stop travel times.
- **Service filters:** Explore available transport services.
- **Responsive interface:** Designed for desktop and mobile screens.
- **Animations and bus photography:** A more engaging visual experience.
- **Multilingual safety notices:** English, Roman Urdu, and Urdu reminders to confirm routes before boarding.

## Getting Started

### Prerequisites

Install Node.js 20.19+ or 22.12+ and npm.

### Installation

Clone the repository:

```bash
git clone https://github.com/m-hashir27/raastaah.git
cd raastaah
npm install
npm run dev
```

Open the localhost URL shown in your terminal, usually `http://localhost:5173`.

### Production Build

```bash
npm run build
```

## Important Limitations

Raasta is an independent prototype, not an official SMTA product or navigation service.

- Route information is manually compiled and may be incomplete or outdated.
- Suggested journeys and transfers depend on the available prototype data.
- Travel times are estimates, not live predictions or official schedules.
- Live tracking, verified fares, and real-time service updates are not implemented.
- Bus photos are illustrative and may not represent Karachi's exact fleet.
- Internet access is required for remote photos and fonts.

Always confirm a bus's route with its conductor before boarding. For Green Line, confirm at the station counter.

Official route information: https://smta.gos.pk/route-map
